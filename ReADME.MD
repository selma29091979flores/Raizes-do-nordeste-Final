# Projeto Raízes do Nordeste - Modelagem de Dados da Lanchonete

Este repositório contém a especificação e modelagem estruturada de dados para o ecossistema da rede de lanchonetes Raízes do Nordeste, desenvolvido como Projeto Multidisciplinar para a UNINTER.

O foco deste projeto foi o mapeamento de entidades operacionais de backend utilizando o formato estruturado JSON.

## 📁 Estrutura do Repositório
* `Lanchonete_Postman_Collection.json`: Massa de testes com os cenários requisitados (T01 a T11).
* `docs/DER.png`: Diagrama de Entidade-Relacionamento com a arquitetura lógica do banco de dados.
* Arquivos `.json`: Modelagem estática das coleções de dados (usuários, pedidos, insumos e estoque).

## 🚀 Como Visualizar
Os arquivos estão prontos para leitura humana e consumo automatizado. Podem ser inspecionados em qualquer IDE (como o VS Code) ou importados em bancos de dados NoSQL orientados a documentos.
